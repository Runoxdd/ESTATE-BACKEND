# Git Status and Uncommitted Changes Check

## Purpose
To check the current git status and identify any uncommitted changes in the ESTATE-BACKEND project.

## Steps to Execute
1. Open a terminal in the project root directory
2. Run `git status` to check the current status
3. Run `git diff` to see the uncommitted changes

## Expected Output
- `git status` should list any modified, added, or deleted files
- `git diff` should show the specific changes made to each file

## Notes
This check will help identify what changes have been made but not yet committed to the git repository.
